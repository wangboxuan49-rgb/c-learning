## 编译与运行

```sh
cc -Wall -Wextra -Wpedantic -std=c11 -fsanitize=address -g ch12/xxx.c -o /tmp/xxx
/tmp/xxx
```

涉及内存分配的章节统一带 `-fsanitize=address`,要求编译零警告、运行无内存错误。

## 验收记录

### 第四周验收(2026-10-04)· 动态内存 · 通过

任务:从标准输入按行读入文本,动态分配的指针数组初始 4 个位置,读满后按两倍扩容;
每行单独分配实际所需长度;结束打印行数与内容并全部释放。

覆盖用例:空输入、2 行、4 行(不扩容)、5 行(扩容一次)、8 行、9 行(扩容两次)、
末尾无换行、超长行。结果:零警告,ASan 无越界、无泄漏、无 double free。

已知限制:超长行(≥ 49 字符)采用截断策略,与下一行输出粘连,属设计取舍。
