# 第三周验收

- 写函数分三步：函数原型（声明）、函数定义、函数调用。原型必须写在调用之前，它只告诉编译器「返回什么类型、要什么参数」，好让编译器检查调用是否合法，本身不产生代码；函数定义才是实现函数体的地方。原型里的形参名可以省略，int array_max(int a[], int x); 和 int array_max(int[], int); 都对。

- C 的参数传递是值传递，在函数里改形参，主调函数的实参不会跟着变。数组是个例外：数组名传进函数时会退化成指向首元素的指针，所以函数里改 a[i]，外面看得到变化。

- 数组不能直接 return 回传。要把结果带出去，就让函数改写传进来的数组（如 array_add 把结果写进 sum[]），或者用 return 返回单个值。

- sizeof 可以验证上面这点：主函数里 int a[10] 的 sizeof(a) 是 40，传进函数后只剩 8，因为那里 a 已经是个指针了。

- 递归函数必须满足两个条件：要有能停下来的最小情况（基准情况），每次调用还要朝它靠近。缺了前者会无限递归，直到栈溢出（Segmentation fault）。

- 递归里代码写在调用之前还是之后，决定了输出顺序。

- 每次递归调用都有自己独立的一份局部变量，互不干扰。to_base_n(129, 8) 的三层递归里三个 r 分别是 2、0、1，所以能先算出来存着、回来再打印。

- 二维数组作函数参数时列数必须写死，写成 int a[][5]，不能写 int a[][]。因为二维数组在内存里是排成一列存放的，编译器必须知道一行有多长，才能算出 a[i][j] 的地址。

- 数组初始化可以用指定初始化器，int a[6] = {1, 2, [4] = 5}; 表示只给 a[0]、a[1]、a[4] 赋值，其余元素自动补 0。

- 求最值时初值要用数组的真实元素打底（max = a[0]），不能用 max = 0。如果数组全是负数，max = 0 会返回一个数组里根本不存在的值。
